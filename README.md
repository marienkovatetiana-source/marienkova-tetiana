# Tetiana Marienkova — Portfolio

Personal portfolio website: UI/UX design & front-end development.

- Stack: HTML, CSS, JavaScript, [Vite](https://vitejs.dev/)
- Hosting: Vercel
- Site plan: [docs/План сайту-портфоліо — чернетка.md](docs/)

## Run locally

```bash
npm install
npm run dev
```

Build for production: `npm run build` (output in `dist/`).
